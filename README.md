# Ansible Role: KVM Hypervisor

Роль для подготовки физических хостов под виртуализацию QEMU/KVM.

## Выполняемые задачи:
- Удаление неиспользуемого пользователя `jony`
- Подготовка LVM-тома `lv_images`, форматирование в XFS и монтирование в `/var/lib/libvirt/images`
- Установка QEMU/KVM и утилит виртуализации
- Настройка и автоматизация работы KSM (Kernel Samepage Merging)
- Скачивание базового облачного образа Ubuntu 24.04 Cloud-Image
- Настройка пула хранения `default` и удаление дефолтной сети NAT (`virbr0`)
